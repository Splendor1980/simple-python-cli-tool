# Simple Python CLI Tool

Простой CLI-проект, который мы разрабатываем вместе с Grok.

## Установка

```bash
git clone https://github.com/Splendor1980/simple-python-cli-tool.git
cd simple-python-cli-tool
pip install -r requirements.txt
```

## Использование

```bash
python main.py hello --name Grok
```
